## 📌 About The Project

Bankist is a modern banking website focused on delivering a clean user interface and a smooth browsing experience.

The main focus was practicing advanced DOM manipulation, event handling, and interactive website components.

## ✨ Features

- **Modal Window:** Interactive account-opening modal.
- **Smooth Scrolling:** Smooth navigation between website sections.
- **Tabbed Component:** Dynamic content switching.
- **Menu Fade Animation:** Interactive navigation hover effects.
- **Sticky Navigation:** Navigation bar stays visible while scrolling.
- **Section Reveal:** Sections appear with scroll-based animations.
- **Lazy Loading Images:** Images load as they approach the viewport.
- **Image Slider:** Interactive slider with navigation controls and dot indicators.

## 🛠️ Technologies Used

- **HTML5** — Semantic website structure.
- **CSS3** — Layout, styling, and animations.
- **JavaScript (ES6+)** — DOM manipulation and event handling.

## 📚 Key Concepts Practiced

- DOM Traversing and Manipulation
- Event Delegation
- Event Bubbling and Capturing
- Event Propagation
- Intersection Observer API
- Event Listeners
- Smooth Scrolling
- Lazy Loading
- JavaScript Classes and Methods
- Working with DOM Elements and Attributes
